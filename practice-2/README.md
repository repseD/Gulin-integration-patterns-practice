Практика 2. Комплексный ремонт скважины

Заявка с несколькими видами работ разбивается на подзаявки, рассылается исполнителям
(бурение, электрика, логистика), расчёты собираются в сводную смету и возвращаются инициатору.

Паттерны:
- Composed Message Processor (основной) — orchestrator
- Splitter — заявка → подзаявки по видам работ
- Message Router — подзаявка → очередь своего исполнителя
- Aggregator — расчёты → единая сводная смета

Запуск:
docker compose up --build

Логи инициатора:
docker compose logs -f initiator

UI RabbitMQ: http://localhost:15672 (guest/guest)
